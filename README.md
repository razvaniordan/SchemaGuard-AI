# SchemeGuard AI

AI-powered solution for interchange fee qualification and card scheme compliance.

## Project Structure

- `frontend/` – user interface
- `backend/` – API and business logic
- `docs/` – documentation
- `tests/` – testing

## Goal

Build a system that simulates and optimizes transaction classification under card network rules (Visa, Mastercard, etc.)
